# Persona: สมหมาย รักงาน

## ข้อมูลทั่วไป: 34 ปี / เจ้าหน้าที่ควบคุมคลังสินค้าและประสานงานคำสั่งซื้อ (ดูแลทั้งสินค้าจับต้องได้และไฟล์ดิจิทัล) / ประสบการณ์ทำงานคลังสินค้า 6 ปี (ใช้ Spreadsheet 3 ปี) / PC สำนักงานคลังสินค้า (จอ 1080p) + แท็บเล็ต/สมาร์ตโฟน Android / ทักษะเทคโนโลยี 2/5

## Quote ที่บ่งบอกตัวตน:
> "กลัวพิมพ์ผิดช่องแล้วสต็อกรวน ยิ่งช่วงหลังมีทั้งของส่งพัสดุกับไฟล์ดิจิทัลให้ลูกค้าโหลด ถ้าปนกันในตารางเดียว หาจุดผิดทีไรเสียเวลาเป็นครึ่งวัน"

## Goals: (2 ข้อ)
1. บันทึกเพิ่มสินค้าใหม่ (ทั้งแบบจับต้องได้และไฟล์ดิจิทัล) ได้สะดวกรวดเร็ว ถูกต้องแม่นยำ โดยไม่ต้องเปิดหลายหน้าต่างหรือสลับโปรแกรมไปมา
2. ตรวจสอบสถานะสต็อกและรับรู้การแจ้งเตือนสินค้าใกล้หมด (Low Stock Alert) ได้ทันที เพื่อแจ้งฝ่ายจัดซื้อได้ทันท่วงที

## Frustrations: (3 ข้อ)
1. ไฟล์ Spreadsheet ที่แชร์กันใช้หลายคนมักถูกแก้ไขข้อมูลทับซ้อน สูตรคำนวณหาย และไม่มีประวัติการเปลี่ยนแปลงที่ตรวจสอบได้
2. สินค้าดิจิทัล (เช่น ซอฟต์แวร์, คีย์ลิขสิทธิ์, E-book) ไม่มีวันหมดสต็อก แต่มักถูกเพื่อนร่วมงานเผลอกรอกจำนวนชิ้น หรือถูกนำไปคำนวณรวมกับสินค้าที่จับต้องได้จนรายงานเพี้ยน
3. ฟอร์มกรอกข้อมูลเดิมไม่มีป้ายกำกับ (Label) ค้างไว้ ทำให้เวลาพิมพ์ข้อมูลยาว ๆ มักสับสนว่ากำลังกรอกช่องใด และไม่มีระบบแจ้งเตือนข้อผิดพลาดก่อนกดยืนยัน

## สิ่งที่ต้องการจากระบบใหม่: (2 ข้อ)
1. ฟอร์มเพิ่มสินค้า (Add Product) ที่มีตัวเลือกแยกประเภทสินค้าชัดเจน (สินค้าจับต้องได้ / สินค้าดิจิทัล) โดยปรับเปลี่ยนช่องกรอกข้อมูลตามประเภทที่เลือกอัตโนมัติ พร้อม Label ค้างไว้เหนือทุกช่อง
2. หน้า Dashboard ที่สรุปยอดรวมของสินค้าแต่ละประเภทอย่างชัดเจน และมีระบบแจ้งเตือนสินค้าที่สต็อกต่ำกว่าเกณฑ์ด้วยสีและข้อความที่สังเกตเห็นได้ทันที

## Journey Map แบบย่อ

งานที่ทำ: **บันทึกสินค้าเข้าคลังหนึ่งรายการ** (ตัวละครหลัก: สมหมาย รักงาน)

| ขั้น | ผู้ใช้ทำอะไร | รู้สึกอย่างไร | จุดสะดุด |
| :--- | :--- | :--- | :--- |
| **1. เปิดระบบ** | เปิดเว็บบราวเซอร์บนเครื่อง PC เข้าสู่หน้า Login กรอกชื่อผู้ใช้และรหัสผ่าน | รู้สึกเฉย ๆ คุ้นเคยกับการเข้าสู่ระบบ | หากจำรหัสผ่านไม่ได้ ไม่มีปุ่มแสดงรหัสผ่าน หรือปุ่มกดยืนยันไม่มีสถานะบอกว่ากำลังตรวจสอบ |
| **2. หาเมนูที่ใช้บันทึก** | มองหาแถบเมนูนำทาง (Sidebar/Navigation) เพื่อเข้าสู่หน้า "เพิ่มสินค้าใหม่ (Add Product)" | คาดหวังว่าจะเข้าถึงเมนูได้ใน 1-2 คลิก | เมนูย่อยซับซ้อน หรือชื่อเมนูไม่สื่อความหมายชัดเจน ทำให้ต้องเดาหรือเสียเวลาค้นหา |
| **3. กรอกข้อมูลสินค้า** | พิมพ์ชื่อสินค้า เลือกว่าเป็นสินค้าจับต้องได้หรือไฟล์ดิจิทัล เลือกหมวดหมู่ กรอกจำนวนและราคา | กังวลว่าจะพิมพ์ผิดช่อง หรือเลือกประเภทสินค้าผิดจนส่งผลต่อการตัดสต็อก | ช่องกรอกไม่มี Label ค้างไว้ (มีแต่ Placeholder จาง ๆ ที่หายไปเมื่อเริ่มพิมพ์) และไม่มีการระบุให้ชัดเจนว่าฟิลด์ไหนจำเป็น (*) |
| **4. กดบันทึก** | เลื่อนหน้าจอลงมาด้านล่างเพื่อกดปุ่ม "บันทึกสินค้า" (Primary Button) | ลังเลและกังวลว่าจะกดผิดปุ่มไปโดนปุ่มยกเลิก หรือกดย้ำซ้ำหลายครั้ง | ปุ่ม "บันทึก" และ "ยกเลิก" วางติดกันเกินไป หรือใช้คำที่ไม่ชัดเจน (เช่น OK/Cancel) ทำให้ไม่มั่นใจ |
| **5. ตรวจว่าบันทึกสำเร็จ** | รอรับการตอบสนองจากระบบเพื่อยืนยันว่าข้อมูลถูกบันทึกเข้าฐานข้อมูลเรียบร้อยแล้ว | โล่งใจหากมีข้อความแจ้งเตือนสีเขียวชัดเจน แต่จะหงุดหงิดหากหน้าจอนิ่งเฉย | หน้าจอนิ่งค้างไม่มี Feedback แจ้งเตือน หรือแสดงแค่ข้อความ error สั้น ๆ โดยไม่บอกว่าฟิลด์ไหนผิดและต้องแก้ไขอย่างไร |

### จุดสะดุดที่เลือกแก้ใน Mockup:
> **จุดสะดุดที่เลือกแก้:** ในขั้นตอนที่ 3 ปัญหาช่องกรอกไม่มี Persistent Label และไม่มีระบบสลับฟิลด์ระหว่างสินค้าจับต้องได้กับสินค้าดิจิทัล ทำให้ผู้ใช้จำไม่ได้ว่ากรอกช่องใดและอาจใส่จำนวนสินค้าดิจิทัลผิดพลาด  
> **แนวทางแก้ไขและตำแหน่ง:** บนหน้าจอ **Add Product** ได้ออกแบบให้มี Persistent Label อยู่เหนือทุกช่องกรอกตลอดเวลา พร้อมสัญลักษณ์ดอกจันสีแดง `*` สำหรับ Required fields และมี Radio Group/Toggle แยกประเภทสินค้าชัดเจน (หากเลือก "สินค้าดิจิทัล" ระบบจะปิดช่องจำนวนสต็อกและแสดงช่องอัปโหลดไฟล์/ลิงก์ดาวน์โหลดแทน) พร้อมกล่องข้อความ Validation Error แสดงใต้ช่องทันทีหากกรอกผิดพลาด
